Reboot Board?

The board will restart and USB will disconnect. Unsaved settings will not be saved. PWM outputs will be interrupted. The host will reconnect to the selected board after restart.

Save & Reboot?

Saving erases and programs flash. The board stops answering HID, CDC, and I2C for a moment, and software generators and monitors are disturbed. Stop software generators first. The board will restart and USB will disconnect. The host will reconnect to verify the applied settings.
